面白いご依頼ですね。圏論と料理のあいだにどんな橋が架けられるか、既に定番の試みがないか軽く調べてからお答えします。


面白いご依頼ですね。しかもこの手の試みは実は既に定番があって、圏論の世界では「**食べ物の圏**」(対象=食材、射=レシピ)という枠組みがよく使われます(ブルリートは「食べ物の圏におけるモナドだ」という有名なジョークまである)。ただ、そこで扱われているのは「料理の手順」であって「美味しさそのもの」ではありません。そこを突っ込んでいくと、とても綺麗な結論が出てきます。順番にご案内します。

## 1. まず「料理の圏」を作る

圏論はたった3つの道具で動きます。

- **対象**(モノ)
- **射**(ものを結ぶ矢印・変換)
- **射の合成**(矢印を繋げること)

これを料理に当てはめると、こうなります。

```
対象 : 食材や料理の状態(生野菜、玉ねぎ、煮込み…)
射   : 調理操作(切る、焼く、煮る、混ぜる…)
合成 : 手順の連結
```

```
生野菜 --[切る]--> 野菜 --[炒める]--> 炒め物 --[煮る]--> 煮込み
```

「切る → 炒める → 煮る」の一連の流れは、ひとつの長い矢印にまとまります。「何もしない」という操作(**恒等射**)を加えれば、これは数学的に**本物の圏**です。比喩ではなく、そのまま圏の公理を満たします。

## 2. 美味しさを「関手」にしてみる → 見事に破綻する

次に、**関手**(圏から圏への「構造を保つ写像」)を使って、美味しさを「料理 → 美味しさの評価」という対応として定式化してみましょう。関手は「合成を保つ」ことを要求します。つまり、*手順全体の美味しさが、各工程の美味しさの合成として書ける*はずだ、ということです。

ところが現実は、この前提を2つの方向から破ります。

**破綻1: 工程の効果が文脈依存**。「焼く」の効果は、牛肉に使えば+、豆腐に使えば?、魚に使えば焦げ注意です。「塩を足す」の効果だって、そこが既に塩気があるかどうかで変わります。つまり「この操作は美味しさをこれだけ変える」と固定できない。関手が要求する「各射にひとつの効果を対応付ける」ことがそもそもできないのです。

もっと明快な反例もあります。もし美味しさが「美味しさ度の順序」への関手なら、*どんな調理工程も美味しさを下げてはいけない*、という帰結になります(順序圏には「下がる」矢印が存在しないから)。しかし「焼きすぎ」は立派な調理工程でありながら美味しさを下げます。**たったひとつの失敗料理が、関手の存在を潰す**。これが圏論の言い分です。

**破綻2: 順序が本質**。「炒めてから煮る」と「煮てから炒める」は、同じ2つの射を合成しただけなのに、味はまったく別物です。

```
煮る ∘ 炒める  ≠  炒める ∘ 煮る
```

順序を入れ替えても結果が変わらない図式(可換図式)が描けない、ということは、この圏は**非可換**であり、合成の順序こそがレシピの本質だということ。圏論の言葉で言い直すと、こうなります。

> **美味しさは関手ではない。**

これは「料理は足し算ではない」「レシピはモジュール化できない」という料理人の直感を、精密な言葉に置き換えたものです。世の中の「素材の点数を足せば完成度が出る」系の美味しさの公式がなぜいつも失敗するか——それは関手としての整合性が、文脈依存と順序依存によって両方の軸で破れているからです。圏論の効用はここにあります。**破綻の位置を指さしで示してくれる**のです。

## 3. それでも圏論の出番がある —「好みの圏」

では圏論は料理に何も言えないのか。いえ、視点を変えると綺麗に機能します。

人それぞれに「美味しさの順序」を考え、これを圏とみなします。

```
対象 : 料理
射   : 「こちらよりこちらの方が美味しい」という矢印
```

これは数学でいう**半順序圏**です。この圏の中で、*すべての料理から矢印が刺さる点*——**終対象**——は「その人にとっての最高の料理」を意味します。そして重要なのは、**万人に共通する終対象は普通存在しない**ということ。これが「好みは人それぞれ」の圏論的表現です。

さらに、二人の好みを「共通の料理圏から美味しさの順序への関手」と見たとき、そのあいだに**自然変換**(関手と関手のあいだの、ズレのない対応)が存在すれば、二人の評価は構造的に一致しています。平たく言えば、**「味が合う」を圏論の言葉で書ける**。双方向にズレがなければ(圏同値)、二人の好みは完全に互換的、ということになります。

## 4. まとめ

- 料理は「食材を対象・レシピを射とする圏」として、数学的にそのまま成立する
- しかし美味しさを関手として捉えると、文脈依存と順序依存によって**2つの軸で破綻する**——これが「料理は足し算ではない」ことの精密な証明
- 一方、好みは人ごとの半順序圏として綺麗に記述でき、**終対象**(最高の料理)や**自然変換**(味が合う)といった概念が、日常の言葉として息を吹き返す

最後にひとつ。冒頭のブルリートのジョークは「モナド」(文脈を保ったまま何度でも合成できる構造)の説明で、トルティーヤ=文脈が具を包む、という見立てです。加藤文元先生の『カルボナーラから学ぶ圏論』も、ハンバーグやカルボナーラで圏・関手・自然変換を解説する好著なので、このあたりの「料理×圏論」に興味があればおすすめです。

今回の枠組みで一番面白いのは「**美味しさは関手ではない**」という否定的な結論だと思うのですが、もし「それでも美味しさを関手として扱いたい」なら、どんな条件を追加すれば救えるか——たとえば「ある一人の人間に固定して」「失敗工程を射から除外して」といった条件——を考えてみるのも楽しいかもしれません。
